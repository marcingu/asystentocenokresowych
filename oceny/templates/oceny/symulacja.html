Symulacja oceny

{% if not podlega %}

Przy obecnym rodzaju zatrudnienia nie podlegasz ocenie okresowej (art. 81 ust. 1 u.s.c.), więc nie ma czego symulować.

{% else %}

To jedynie przypuszczenie, a nie zapowiedź oceny. Ocenę wystawia przełożony na podstawie wszystkich informacji, które posiada - także tych, których nie ma w systemie EZD RP: obserwacji, rozmów, jakości pracy, współpracy i dodatkowych osiągnięć.

Symulacji nie widzi przełożony ani kadry. System jej nie zapisuje - po wyjściu ze strony znika.

{% if ocena_sporzadzona %}

Twoja ocena za bieżący okres jest już sporządzona. Symulacja dotyczy kolejnego okresu: obejmuje kryteria obowiązkowe Twojego arkusza i nie korzysta z danych EZD RP.

{% endif %}
